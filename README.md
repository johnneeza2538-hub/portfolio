# พอตโฟลิโอ

## วิธีใส่ข้อมูลจริง

1. **ชื่อ/แบรนด์** — ค้นหาคำว่า `[ชื่อของคุณ]` ใน [index.html](index.html) แล้วแก้เป็นชื่อจริง
2. **รูปโปรไฟล์** — ใส่ไฟล์ภาพที่ `images/profile/avatar.jpg` (แนะนำภาพสี่เหลี่ยมจัตุรัส) จะโชว์ข้างชื่อคุณในส่วน Hero อัตโนมัติ ถ้ายังไม่มีไฟล์จะโชว์กรอบ placeholder บอก path ให้
3. **อีเมล/โซเชียล** — แก้ลิงก์ในส่วน Contact ของ [index.html](index.html) (ค้นหา `your.email@example.com`, `Behance`, `LinkedIn`, `Instagram`)
4. **ประวัติ (Bio)** — แก้ข้อความในส่วน `.about__bio` ของ [index.html](index.html)
5. **ผลงาน** — แก้ไฟล์ [js/data.js](js/data.js)
   - แก้ `title`, `tag`, `desc` ให้ตรงกับผลงานจริง
   - ใส่รูปภาพในโฟลเดอร์ที่ตรงกัน แล้วตั้งชื่อไฟล์ให้ตรงกับพาธที่กำหนดไว้ เช่น
     - `images/game-maps/map-01-a.jpg`
     - `images/game-ui/ui-01.jpg`
     - `images/aso/aso-01.jpg`
   - ถ้ายังไม่มีรูป การ์ดจะแสดง placeholder บอกพาธไฟล์ที่ต้องใส่โดยอัตโนมัติ
   - **แผนที่เกม (gameMapsData)** ใช้ฟิลด์ `images: [...]` เป็น array แทน `image` เดี่ยว — ใส่รูปแยกเป็นท่อน ๆ ได้กี่รูปก็ได้ (ไม่ต้องต่อไฟล์เองก่อน) ตอนคลิกดูรายละเอียดระบบจะเรียงต่อกันแนวตั้งให้ดูต่อเนื่องเหมือนภาพเดียวยาว ๆ อัตโนมัติ (การ์ดหน้ารวมผลงานใช้รูปแรกในลิสต์เป็นภาพตัวอย่าง)
   - หมวดอื่น (`gameUiData`, `asoData`) ยังใช้ `image` พาธเดี่ยวตามเดิม แต่ถ้าอยากใช้ `images: [...]` แบบเดียวกันก็ทำได้เช่นกัน
   - เพิ่ม/ลบผลงานได้โดยเพิ่ม/ลบ object ในแต่ละ array (`gameMapsData`, `gameUiData`, `asoData`)
6. **พื้นหลัง splash screen ของ section แผนที่เกม** — ใส่ไฟล์ภาพที่ `images/game-maps/splash.jpg` (แนะนำภาพแนวนอนกว้าง ๆ) ระบบจะใช้เป็นพื้นหลังของ section นี้อัตโนมัติ พร้อม overlay ให้ตัวหนังสืออ่านง่าย ถ้ายังไม่มีไฟล์ ส่วนนี้จะโชว์พื้นหลังปกติเฉย ๆ ไม่มี error ปรับ path ได้ที่ [css/style.css](css/style.css) (`.portfolio--splash`)
